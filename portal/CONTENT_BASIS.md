# Content basis

The supplied product source and design plan are the basis for this portal. The site presents scoring infrastructure, with competition data as a concrete example.

Generated from the actual checkout:

- Product version, Python requirement, optional extras, project URLs, public SDK signatures/docstrings, and StatPack interface.
- Gateway OpenAPI, paths, request/response schemas, adapter and dataset catalogs.
- EBA Players/Teams input, canonical mapped rows, exact score profiles/buckets, dataset/adapter hashes, verified downloads, and runnable StatPacks.
- Available documentation version/channel manifest and matching README release highlights.

Editorial content translates Core/App/Gateway into DevKit/Local/API, explains use cases, and describes the invite-only hosted-access model from the supplied plan. The EBA and Elevate302 strip identifies source-backed workflows; the site does not claim a customer count or invented logos.

Potential applications (bots, dashboards, awards, pipelines, reports, broadcast data, research, and internal tools) describe what developers can build around scoring output. The portal does not claim to provide those downstream products itself.

The anonymous playground uses clearly labeled saved output. The live label is applied to actual authenticated responses or to a responding API connection with a key-required label. No simulated calculation is presented as a live result.

Organization setup uses the actual project Issues URL, because the supplied inputs contain no verified Discord invite or contact email. It prepares a draft for review and does not send a message on the user's behalf.
